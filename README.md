# CreditsPlan

### AI Coding Plans, Pricing, Quotas & Model Comparison
### AI Coding 套餐、价格、额度与模型对比平台

**CreditsPlan** is an independent platform for comparing AI coding subscriptions, pricing, usage quotas, supported models, and plan conditions.

**CreditsPlan** 是一个独立的 AI Coding 套餐对比与订阅决策平台，帮助开发者比较价格、额度、支持模型、使用条件和价格变化。

- 🇨🇳 China / 中国站：https://creditsplan.cn
- 🌍 Global / 国际站：https://www.creditsplan.com

## 🔍 What You Can Compare / 可对比内容

- AI Coding subscription plans / AI Coding 套餐
- Pricing and billing cycles / 价格与计费周期
- Usage quotas and limits / 使用额度与限制
- Supported AI models / 支持的 AI 模型
- Coding tool compatibility / 编程工具兼容性
- Plan conditions and restrictions / 套餐条件与限制
- Price changes and verification dates / 价格变化与核验日期
- Official source references / 官方来源参考
